# HBD Hani 💙

Landing page ulang tahun cute + islami untuk Hani, dengan tema biru.

## Cara menjalankan
1. Buka `index.html` di browser.
2. Semua foto sudah ada di folder `assets`.
3. Untuk lagu MP3: klik **Pilih MP3** lalu pilih file `.mp3` dari perangkat.
4. Kalau ingin lagu langsung tersedia di website, taruh file MP3 di folder `assets` dan ubah bagian audio di HTML sesuai nama file.

## Catatan
Browser biasanya tidak mengizinkan musik autoplay sebelum ada interaksi pengguna. Karena itu tombol/file picker musik dibuat supaya aman dipakai di HP maupun laptop.
